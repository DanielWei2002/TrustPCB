# DICC computational efficiency

Scientific experiment identity: `rq3_computational_efficiency`.

Saved five-repetition DICC benchmark on 821 development crops, batch 1. Timings include the recorded pipeline work and exclude startup/model loading, provenance validation, hashing and output writes. Sample SD is not a confidence interval. These measurements are not evidence of factory-ready or real-time operation.
